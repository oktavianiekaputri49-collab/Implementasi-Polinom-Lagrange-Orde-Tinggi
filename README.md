# Implementasi-Polinom-Lagrange-Orde-Tinggi
Mini project metode numerik menggunakan Interpolasi Lagrange orde tinggi untuk melakukan pendekatan nilai fungsi pada titik tertentu, yaitu f(0,5).  Dalam project ini dilakukan pembentukan polinom Lagrange dari beberapa titik data untuk memperoleh estimasi nilai fungsi secara numerik menggunakan Microsoft Excel.
